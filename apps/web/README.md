# @kitchen-ops/web

The Vue 3 PWA: sign-in, owner 2FA setup and the product list. It talks only to its own origin, which forwards `/api/*` to the API.

How to run, build and deploy it: the root [`README.md`](../../README.md) ("Web app" and "Deploying"). What it does and doesn't do yet: [`docs/architecture.md`](../../docs/architecture.md).
