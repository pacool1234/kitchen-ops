# 0009. Runtime: Node 24 LTS

- Status: Accepted
- Date: 2026-10-14

## Context

Vite's Rolldown native binary is an optional dependency requiring Node ^20.19 or >=22.12; on Node 22.8 pnpm silently skipped it and Vite crashed.

## Decision

Node 24 LTS, pinned with `.node-version` (read by fnm and Render) and `engines` in the root package.json.

## Alternatives considered

Staying on Node 22.x.
